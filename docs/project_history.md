## ЗАПРОС 1: Создание алгоритма поиска графонов, соответствующих концепциям

**Дата:** 2025-08-10

**Описание:** Пользователь запросил реализацию полного алгоритма на Python для:
1. Извлечения концепций из корпуса документов
2. Построения локальных графонов для каждой концепции
3. Индексирования и поиска графонов по схожести

**Спецификация включала 4 этапа:**

### Этап 1: Предварительная обработка и извлечение концепций
- Очистка текста и нормализация
- Использование spaCy/NLTK для токенизации и лемматизации
- NER для извлечения сущностей
- Тематическое моделирование (Gensim) и кластеризация эмбеддингов

### Этап 2: Построение графов для каждой концепции
- Извлечение контекста концепции
- Формирование взвешенного графа соконкуренции терминов
- Использование NetworkX для построения графа

### Этап 3: Аппроксимация графа графоном
- Извлечение матрицы смежности
- Непараметрическая оценка функции W(x,y) (kernel smoothing, piecewise constant)
- Интегрирование компонента S(x) для локальных особенностей
- Сохранение представления в виде пары функций (W, S)

### Этап 4: Индексирование и поиск
- Извлечение дескрипторов из графонов (интегральные характеристики, спектральные особенности)
- Использование FAISS или Annoy для векторного поиска
- Обработка запроса (построение графона для запроса)
- Сравнение и ранжирование по cosine similarity или cut distance
- Возврат результатов отсортированных по подобию

**Результат:** Реализован полный проект с модульной архитектурой

### 2. Core модули:

#### `semgraphex/preprocess.py`
- `load_spacy()`: загрузка spaCy модели с автоматической загрузкой при отсутствии
- `normalize()`: нормализация текста (удаление URL, приведение к нижнему регистру)
- `sentences()`: разбиение текста на предложения
- `tokenize()`: токенизация с удалением стоп-слов и лемматизацией

#### `semgraphex/concepts.py`
- `ConceptCandidate`: класс для представления кандидатов в концепции
- `extract_ner_concepts()`: извлечение концепций через NER
- `extract_statistical_terms()`: извлечение часто встречающихся терминов
- `merge_concept_lists()`: объединение списков концепций с выбором лучших
- `collect_concept_contexts()`: сбор контекстных окон для каждой концепции

#### `semgraphex/graph_builder.py`
- `build_cooccurrence_graph()`: построение взвешенного графа соконкуренции терминов
  - Окно соседства (window) для определения пар терминов
  - Минимальный вес для фильтрации редких связей
  - Удаление изолированных узлов

#### `semgraphex/graphon.py`
- `GraphonRepresentation`: dataclass для хранения графон-представления
  - W: дискретизированная матрица графона
  - S: сигнал степени узла (centrality)
  - nodes: упорядоченные метки узлов
  - meta: метаданные
- `estimate_graphon()`: оценка графона для графа
  - Упорядочение узлов по степени
  - Построение матрицы смежности
  - Нормализация весов
  - Интерполяция на grid размером grid_size
  - Гауссовский фильтр для сглаживания
- `downsample()`: понижение дискретизации матрицы
- `resize_to_grid()`: переподгонка размера матрицы на нужную сетку

#### `semgraphex/index.py`
- `VectorIndex`: унифицированный интерфейс для индексирования
  - Поддержка FAISS (IndexFlatIP для cosine similarity)
  - Fallback на Annoy
  - Методы: `add()`, `build()`, `search()`
  - Автоматическая нормализация для cosine similarity

#### `semgraphex/pipeline.py`
- `ConceptGraphonIndexer`: основной класс конвейера
  - `fit()`: обучение на корпусе документов
    1. Извлечение концепций (NER + статистика)
    2. Построение графов для каждой концепции
    3. Оценка графонов
    4. Извлечение вектор-дескрипторов
    5. Индексирование в FAISS/Annoy
  - `search()`: поиск по запросу
    1. Построение графона для запроса
    2. Извлечение вектора запроса
    3. Поиск K ближайших соседей
    4. Возврат результатов с scores
- `ConceptSearchResult`: dataclass для результата поиска

## ЗАПРОС 2: Создание алгоритма генерации Graphex

**Дата:** 2026-08-30 (продолжение)

**Описание:** Пользователь запросил реализацию переходов от локальных графонов концепций к глобальной сети концепций (graphex).

**Спецификация включала 4 ключевых шага:**

### Шаг 1: Вычисление межконцептуальных подобий
- Извлечение дескрипторов из графонов
- Вычисление косинус-подобия между дескрипторами
- Возможность использования cut distance метрики

### Шаг 2: Построение межконцептуального графа
- Граф, где узлы = концепции
- Рёбра с весом = мера подобия
- Пороговое отсечение для разреженности

### Шаг 3: Оценка функций графекса
- Снижение размерности (PCA, t-SNE, UMAP) для получения латентных координат
- Оценка функции W(x,y) на латентном пространстве
- Опциональная оценка S(x) для моделирования локальных эффектов

### Шаг 4: Получение графекса
- Комбинация результатов в тройку (I, S, W):
  - **W**: R₊² → [0,1] — вероятность связи между концепциями
  - **S**: сигнал для локальных эффектов (hubness)
  - **I**: список изолированных связей

**Результат:** Расширение проекта с модулем графекса

## РЕАЛИЗАЦИЯ: Интеграция Graphex

### Новые файлы:

#### `semgraphex/graphex.py` (новый модуль)
- `GraphexRepresentation`: dataclass для представления графекса
  - `concepts`: список меток концепций
  - `coords`: латентные координаты (n, 2) в [0,1]²
  - `W_grid`: дискретизированная оценка W(x,y)
  - `S`: сигнал hubness каждой концепции
  - `I`: список промежуточных рёбер (concept_i, concept_j, weight)
  - `meta`: метаданные
  - `top_hubs()`: метод для получения топ-K концепций по центральности

- `build_graphex_from_concepts()`: построение графекса
  1. Нормализация вектор-дескрипторов для косинус-подобия
  2. Вычисление матрицы подобия
  3. PCA для получения латентных координат
  4. Масштабирование координат в [0,1]
  5. Построение списка рёбер выше порога подобия
  6. Вычисление S(x) как нормализованной взвешенной степени
  7. Оценка W(x,y) путём биннирования подобий в сетку и сглаживания

## ТЕХНИЧЕСКАЯ АРХИТЕКТУРА

```
Текстовый корпус
        ↓
    [Preprocessing]
  (normalize, tokenize, sentence-split)
        ↓
    [Concepts Extraction]
  (NER + Statistical Terms + Merge)
        ↓
 Per-concept pipeline (параллельно):
    [Context Collection] → [Co-occurrence Graph] → [Graphon Estimation] → [Descriptor Extraction]
        ↓
  [Graphon Descriptors] (n_concepts, vector_dim)
        ↓
  [Vector Indexing] (FAISS или Annoy)
        ↓
 Query pipeline:
    [Query Text] → [Graphon] → [Descriptor] → [Search in Index] → [Results with Scores]
        ↓
  [ConceptSearchResult]

Дополнительно (Graphex):
  [All Graphon Descriptors]
        ↓
  [Pairwise Cosine Similarity]
        ↓
  [Edge List] (I) - пороговое отсечение
        ↓
  [PCA Embedding] → Latent Coordinates
        ↓
  [W(x,y) Estimation] - биннирование и сглаживание
        ↓
  [S(x) Computation] - hubness сигнал
        ↓
  [GraphexRepresentation] (concepts, coords, W_grid, S, I, meta)
```

## КЛЮЧЕВЫЕ ПАРАМЕТРЫ И КОНФИГУРАЦИЯ

### ConceptGraphonIndexer
- `grid_size`: размер дискретизационной сетки для графона (по умолчанию 64)
- `smooth_sigma`: сигма для гауссова фильтра (по умолчанию 1.0)
- `descriptor_blocks`: количество блоков для downsampling (по умолчанию 16)
- `max_concepts`: максимальное количество концепций (по умолчанию 200)

### build_graphex()
- `dim`: размерность латентного пространства (по умолчанию 2)
- `grid_size`: размер сетки W(x,y) (по умолчанию 64)
- `similarity_threshold`: порог подобия для включения в граф (по умолчанию 0.5)
- `smoothing_sigma`: сигма для сглаживания W_grid (по умолчанию 1.0)

## ИСПОЛЬЗОВАНИЕ И ПРИМЕРЫ

### Базовое использование:
```python
from semgraphex import ConceptGraphonIndexer

corpus = [
    "Graph neural networks are powerful...",
    "Neural networks learn representations...",
    ...
]

# Обучение
indexer = ConceptGraphonIndexer(grid_size=32, descriptor_blocks=9)
indexer.fit(corpus)

# Поиск по запросу
results = indexer.search("graph neural networks", k=5)
for r in results:
    print(f"{r.concept}: {r.score:.3f}")
```

### Построение глобального графекса:
```python
# После обучения
graphex = indexer.build_graphex(similarity_threshold=0.55)

# Получение топ-концепций по центральности
hubs = graphex.top_hubs(k=10)
print(hubs)  # [(concept_name, hubness_score), ...]

# Доступ к компонентам
print(f"Латентные координаты: {graphex.coords.shape}")  # (n_concepts, 2)
print(f"Матрица W(x,y): {graphex.W_grid.shape}")       # (64, 64)
print(f"Сигнал hubness: {graphex.S.shape}")            # (n_concepts,)
print(f"Рёбра в графе: {len(graphex.I)}")
```

## ЗАКЛЮЧЕНИЕ

Проект **semgraphex** — это исследовательский прототип для анализа семантических структур через призму графонов и графексов. Он предоставляет модульную архитектуру, где каждый этап конвейера может быть заменён более продвинутой реализацией. Текущая версия использует простые непараметрические методы для доступности и понимаемости кода, при этом оставаясь достаточно гибкой для экспериментов с более сложными алгоритмами.
