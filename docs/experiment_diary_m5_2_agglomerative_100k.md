# M5.2 — ConceptNet 100k: connectivity-constrained agglomerative Haken coarsening

Дата постановки: 2026-09-11

## Цель

Повторить M5 на том же реальном 100 000-узловом подграфе ConceptNet, заменив только алгоритм укрупнения графа: вместо `connectivity_matching` использовать `connectivity_agglomerative`.

Главный вопрос: исчезает ли ограничение pairwise matching и можно ли реально получать заданное сжатие 35% и 50% на каждом уровне, сохраняя при этом медленную макродинамику лучше или хуже исходного M5?

## Термины простыми словами

- **Coarsening / укрупнение** — объединение нескольких исходных вершин в одну супервершину.
- **Pairwise matching** — старый алгоритм, где за один шаг вершина может войти только в одну пару. Из-за этого M5 не смог реально выполнить 35% и 50% сжатия.
- **Agglomerative clustering / агломеративная кластеризация** — алгоритм, который начинает с отдельных вершин и последовательно сливает ближайшие группы. Уже выросший кластер может снова сливаться с соседним кластером в том же шаге.
- **Connectivity-constrained / с ограничением связности** — разрешается сливать только кластеры, между которыми есть хотя бы одно ребро текущего графа. Поэтому каждая итоговая супервершина представляет связную область графа.
- **Haken-space / Haken-пространство** — координаты вершины по выбранным медленным спектральным модам. Близкие точки имеют похожее участие в медленной коллективной динамике.
- **Centroid / центр кластера** — средняя Haken-координата всех вершин кластера с весами по числу вершин. После каждого слияния центр пересчитывается.
- **Priority queue / приоритетная очередь** — структура данных, которая быстро выдаёт текущую ближайшую допустимую пару кластеров.
- **Target reduction** — желаемая доля удалённых вершин на одном уровне. Проверяются 0.35 и 0.50.
- **Subspace distance** — изменение пространства медленных коллективных режимов между соседними масштабами.
- **Eigenvalue error** — изменение собственных значений медленных режимов, то есть их характерных временных масштабов.
- **Trajectory error** — отличие полной линейной динамики fine и coarse графов после обратного разворачивания coarse-состояния.
- **Plateau** — несколько соседних масштабов, на которых макродинамические характеристики остаются достаточно стабильными несмотря на сжатие.

## Алгоритм

На каждом масштабе:

1. строится нормализованный оператор `S = D^{-1/2} A D^{-1/2}`;
2. вычисляются медленные спектральные моды;
3. вершина `i` получает Haken-координату `z_i = (phi_1(i), ..., phi_r(i))`;
4. из рёбер текущего графа создаются допустимые пары кластеров;
5. пары помещаются в priority queue по расстоянию между centroid в Haken-пространстве;
6. сливается ближайшая допустимая пара;
7. центр нового кластера становится взвешенным средним центров двух частей;
8. его граница с соседними кластерами обновляется;
9. шаги 6–8 повторяются, пока число кластеров не уменьшится на заранее заданную долю;
10. строится quotient graph `A' = P^T A P`;
11. на новом графе спектр и динамика вычисляются заново.

Важное отличие от pairwise matching: один растущий кластер может получить много исходных вершин за один уровень, поэтому потолка «только непересекающиеся пары» больше нет.

## Что не меняется относительно M5

- официальный ConceptNet 5.7 dump;
- английский язык;
- отношения `RelatedTo`, `IsA`, `PartOf`, `HasA`, `UsedFor`, `HasProperty`;
- тот же детерминированный алгоритм выделения связного ядра ровно из 100 000 узлов;
- `log1p` веса;
- неориентированный граф;
- Haken embedding;
- спектральные параметры;
- линейная диагностическая динамика;
- random seed 1729;
- plateau thresholds.

То есть M5.2 меняет только способ построения partition.

## Два режима

### Основной

`target_reduction = 0.35`.

Ожидаемая идеальная последовательность размеров при точном достижении цели начинается примерно так:

`100000 -> 65000 -> 42250 -> 27462 -> ...`.

### Стресс-режим

`target_reduction = 0.50`.

При точном достижении цели:

`100000 -> 50000 -> 25000 -> 12500 -> ...`.

## Критерии технического успеха

1. полный Haken regression suite проходит до запуска данных;
2. подготовленный граф содержит ровно 100 000 узлов;
3. агломеративный алгоритм не создаёт плотную `N x N` матрицу расстояний;
4. каждый кластер остаётся связным по графу;
5. фактическое сжатие соответствует целевому, если связность не создаёт реального ограничения;
6. оба режима завершаются или явно фиксируют ресурсный/алгоритмический blocker.

## Критерии научной оценки

Для каждого перехода сохраняются:

- число узлов;
- число выбранных медленных мод `r`;
- достигнутая доля сжатия;
- subspace distance;
- slow eigenvalue error;
- trajectory error;
- наличие/отсутствие plateau.

Пороговые значения не меняются после просмотра результатов.
