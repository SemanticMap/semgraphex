# Дневник эксперимента M5 — Haken-coarsening на реальном ConceptNet, 100 000 узлов

Дата начала: 2026-09-10

## 1. Цель

Проверить, сохраняются ли устойчивые медленные макродинамические структуры при последовательном сжатии реального семантического графа ConceptNet размером ровно 100 000 узлов.

Это первый этап после синтетического M4.1, где входной граф больше не содержит специально заложенной нами иерархии.

Главный вопрос:

> Есть ли на реальном ConceptNet диапазон масштабов, в котором граф существенно уменьшается, а число и геометрия медленных коллективных режимов остаются примерно стабильными?

## 2. Термины простыми словами

- **ConceptNet** — открытая семантическая сеть: узлы соответствуют словам и понятиям, а рёбра задают отношения вроде `IsA` («является видом»), `PartOf` («является частью»), `UsedFor` («используется для») и `RelatedTo` («связано с»).
- **Узел / node** — отдельное понятие или языковая единица в графе.
- **Ребро / edge** — связь между двумя узлами.
- **Вес ребра / edge weight** — численная сила связи. В эксперименте используется `log1p(weight) = log(1 + weight)`, чтобы очень большие исходные веса не доминировали чрезмерно.
- **Степень узла / degree** — суммарное количество или вес связей узла с другими узлами. В отборе 100k используется взвешенная степень.
- **Связанная компонента / connected component** — часть графа, внутри которой от любого узла можно добраться по рёбрам до любого другого.
- **Наибольшая связанная компонента / LCC** — самая большая такая часть графа.
- **Индуцированный подграф / induced subgraph** — граф, в котором после выбора набора узлов сохраняются все исходные ConceptNet-рёбра между выбранными узлами.
- **Streaming / потоковая обработка** — чтение большого файла строка за строкой без загрузки всего файла и всех рёбер в оперативную память.
- **Sparse matrix / разреженная матрица** — матрица смежности, в которой хранятся только существующие рёбра, а не огромная таблица из всех возможных пар узлов.
- **Матрица смежности `A`** — численное представление графа: `A_ij` показывает силу связи между узлами `i` и `j`.
- **Нормализованная матрица смежности `S = D^{-1/2} A D^{-1/2}`** — версия матрицы смежности, в которой влияние узлов корректируется на их степень. Это уменьшает доминирование очень высокостепенных хабов.
- **Хаб / hub** — узел с очень большим числом связей.
- **Мода / mode** — характерный коллективный паттерн изменения состояния всей сети. Математически в текущей реализации мода соответствует собственному вектору нормализованного оператора.
- **Собственный вектор / eigenvector** — направление состояния системы, которое оператор не поворачивает в другое направление, а только умножает на число.
- **Собственное значение / eigenvalue** — число, показывающее, насколько сильно соответствующая мода усиливается или ослабляется оператором.
- **Спектр / spectrum** — набор собственных значений оператора.
- **Медленная мода / slow mode** — коллективный режим, который затухает медленнее быстрых мелкомасштабных изменений.
- **Медленное подпространство / slow subspace** — пространство, натянутое на несколько выбранных медленных мод; его можно понимать как набор основных макродинамических направлений системы.
- **Кандидат в параметр порядка / order-parameter candidate** — амплитуда одной из выбранных медленных мод. Это пока кандидат, потому что строгая зависимость быстрых переменных от этих параметров (slaving) ещё не доказана.
- **Параметр порядка / order parameter** — в синергетике Хакена небольшое число коллективных переменных, определяющих макроскопический режим большого числа элементов.
- **Coarsening / укрупнение, сжатие графа** — объединение нескольких близких по выбранному критерию исходных узлов в одну супервершину.
- **Супервершина / coarse node** — вершина сжатого графа, представляющая группу исходных понятий.
- **Fine graph** — граф до очередного шага укрупнения.
- **Coarse graph** — граф после очередного шага укрупнения.
- **Hierarchy / иерархия масштабов** — последовательность `G0 -> G1 -> G2 -> ...`, где каждый следующий граф грубее предыдущего.
- **Target reduction `c`** — доля вершин, которую алгоритм пытается убрать за один шаг. `c=0.35` означает примерно 35%, `c=0.50` — примерно половину.
- **Plateau / плато** — несколько последовательных масштабов, между которыми основные макродинамические характеристики меняются мало, несмотря на уменьшение числа узлов.
- **Subspace distance** — расстояние между медленными подпространствами соседних масштабов. Ноль означает практически одинаковые макродинамические направления; большие значения означают их сильное изменение.
- **Trajectory / траектория** — изменение искусственно заданного состояния сети во времени после начального возмущения.
- **Perturbation / возмущение** — начальный «толчок» системе, например активация одного узла, хаба или случайной группы узлов.
- **Linear dynamics / линейная динамика** — модель `dx/dt = (-alpha I + beta S)x`, используемая как диагностический эксперимент. Она не утверждается как истинная динамика языка; это контролируемый способ проверить устойчивость структуры.
- **Spectral abscissa** — наибольшая скорость роста среди линейных мод. Отрицательное значение означает устойчивую систему: возмущения со временем затухают.
- **Eigengap / спектральный разрыв** — заметный промежуток между соседними собственными значениями. Большой разрыв может отделять несколько медленных коллективных мод от более быстрых.
- **Detector / детектор плато** — набор формальных критериев, который решает, считать ли несколько последовательных переходов устойчивым плато.
- **Gate / критерий допуска** — одно из условий детектора: стабильность числа мод, расстояния подпространств, спектра и динамических траекторий.
- **Baseline / базовый метод сравнения** — более простой метод, с которым нужно сравнивать Haken-подход, чтобы не приписать ему обычный эффект графового сжатия. Baselines будут отдельным последующим этапом.

## 3. Источник данных

Используется официальный ConceptNet 5.7 dump:

`conceptnet-assertions-5.7.0.csv.gz`

Версия фиксируется как `5.7.0`.

Используемые английские отношения:

- `RelatedTo`;
- `IsA`;
- `PartOf`;
- `HasA`;
- `UsedFor`;
- `HasProperty`.

Минимальный исходный вес связи: `1.0`.

На первом M5 этапе граф делается неориентированным: если ConceptNet содержит смысловую связь `i -> j`, при построении оператора она учитывается симметрично. Это упрощение нужно явно помнить: исходные отношения ConceptNet могут иметь направление, но данный эксперимент изучает прежде всего геометрию связности, а не направление семантического перехода.

## 4. Почему нельзя просто взять первые 100 000 узлов

Порядок строк в dump не должен определять научный результат. Если взять первые попавшиеся записи, можно получить тематически или технически смещённый фрагмент.

Поэтому заранее фиксируется детерминированный двухпроходный отбор.

### Шаг 1. Первый streaming-проход по всему dump

Для каждой строки проверяется:

1. оба узла английские (`/c/en/...`);
2. тип отношения входит в заранее заданные шесть отношений;
3. вес конечен и не меньше `1.0`;
4. связь не является петлёй узла на самого себя.

Для подходящих рёбер вычисляется взвешенная степень каждого узла:

`degree(i) = sum_j log(1 + weight_ij)`.

Одновременно алгоритм Union-Find определяет связанные компоненты.

**Union-Find / система непересекающихся множеств** — компактная структура данных, которая во время чтения рёбер отслеживает, какие узлы уже соединены путями друг с другом. Для этого не требуется хранить все рёбра в памяти.

### Шаг 2. Выбор наибольшей связанной компоненты

После первого прохода выбирается компонент с максимальным числом узлов.

Это защищает эксперимент от случайного набора маленьких несвязанных островков.

### Шаг 3. Выбор ровно 100 000 узлов

Внутри LCC узлы сортируются по убыванию взвешенной степени.

Берутся первые 100 000.

При одинаковой степени используется лексикографический порядок URI, чтобы выбор был полностью воспроизводимым и не зависел от порядка обработки.

Это означает, что M5 изучает **100 000 наиболее структурно связанных английских понятий основной компоненты ConceptNet**, а не случайную выборку всех понятий.

Это ограничение интерпретации будет сохранено в итоговом отчёте.

### Шаг 4. Второй streaming-проход

Dump читается ещё раз.

Сохраняются все подходящие ConceptNet assertions, у которых оба конца входят в выбранные 100 000 узлов.

Получается индуцированный реальный ConceptNet-подграф.

Если хотя бы один из выбранных 100 000 узлов не встречается ни в одном ребре этого индуцированного графа, эксперимент аварийно останавливается: запрещено незаметно назвать граф «100k», если фактически узлов меньше.

## 5. Подготовка матрицы графа

Для повторных assertions между одной парой узлов вклады суммируются.

Вес каждого assertion преобразуется:

`w' = log(1 + w)`.

После этого строится разреженная CSR-матрица `A`.

**CSR (Compressed Sparse Row)** — формат хранения разреженной матрицы по строкам; он хранит только ненулевые элементы и их индексы.

Затем строится нормализованный оператор:

`S = D^{-1/2} A D^{-1/2}`,

где `D` — диагональная матрица степеней.

## 6. Спектральный анализ

На каждом уровне иерархии вычисляются до 48 ведущих собственных пар оператора `S`.

**Собственная пара** — собственное значение вместе с соответствующим ему собственным вектором.

Из них алгоритм выбирает не более 24 медленных мод-кандидатов.

Цель — найти небольшой набор коллективных направлений, которые отделяются по временам релаксации от остальных.

## 7. Диагностическая динамика

На каждом масштабе запускается линейная система:

`dx/dt = (-alpha I + beta S)x`.

Здесь:

- `x` — состояние всех узлов;
- `I` — единичный оператор;
- `alpha=1` — общее затухание;
- `beta` автоматически выбирается близко к критическому, но с запасом устойчивости `0.05`;
- `S` передаёт влияние между связанными узлами.

**Критический режим** — область параметров, где одна или несколько мод затухают очень медленно и поэтому начинают доминировать над быстрыми.

Используются четыре типа возмущений:

1. один отдельный узел;
2. случайный гауссовский вектор по всем узлам;
3. разреженная случайная активация примерно 0.1% узлов;
4. активация самого высокостепенного хаба.

На M5 используется по одному возмущению каждого типа, то есть четыре траектории на уровень.

Временная сетка: 41 точка от `t=0` до `t=8`.

## 8. Haken-coarsening

Для каждого узла строится координата по выбранным медленным модам.

Узлы с близкими координатами и допустимой структурной связью объединяются методом `connectivity_matching`.

**Embedding / вложение** — представление каждого узла набором чисел. Здесь числа показывают участие узла в медленных коллективных модах.

**Matching / сопоставление** — выбор пар узлов для объединения.

**Connectivity matching** — объединение ограничивается структурно связанными кандидатами, а не любыми двумя точками во всём пространстве.

После объединения строится quotient graph.

**Quotient graph / фактор-граф** — граф, где каждая группа объединённых исходных узлов заменена одной супервершиной, а веса связей между группами агрегируются.

## 9. Два режима M5

Основной режим:

`target_reduction = 0.35`.

Он выбран до запуска реального графа, потому что M4.1 на synthetic positive control показал устойчивое поведение при умеренном шаге.

Контрольный стресс-режим:

`target_reduction = 0.50`.

Он не используется для подбора результата; его задача — проверить, повторяется ли на реальном графе эффект разрушения структуры при более агрессивном шаге.

Остальные параметры одинаковы.

Максимум: 8 шагов coarsening, то есть не более 9 уровней графа включая исходный.

## 10. Что измеряется между соседними масштабами

Для каждого перехода `Gs -> G{s+1}` сохраняются:

1. число узлов до и после;
2. фактическая доля удаления узлов;
3. число выбранных медленных мод `r`;
4. subspace projection distance;
5. максимальное изменение медленных eigenvalues;
6. относительная ошибка динамической trajectory;
7. причина остановки или недостаточного сжатия, если она возникла.

### Subspace projection distance

Сравнивает не отдельные собственные векторы по именам, а пространства, которые они вместе задают.

Это важно, потому что при близких eigenvalues отдельные eigenvectors могут вращаться внутри почти того же подпространства.

### Trajectory error

Показывает, насколько динамика coarse graph после lifting обратно на fine nodes отличается от исходной динамики.

**Lifting** — перенос состояния супервершины обратно на все исходные узлы, которые она представляет.

## 11. Критерий plateau

В M5 plateau считается кандидатом, если не менее двух последовательных переходов одновременно выполняют:

- `r` не меняется;
- subspace distance <= `0.45`;
- trajectory error <= `0.50`;
- eigenvalue error <= `0.30`;
- реальное уменьшение числа узлов >= `10%` за переход.

Эти пороги фиксируются **до просмотра реального результата**.

Важно: найденное plateau будет называться **candidate plateau**, а не доказанной естественной семантической иерархией.

## 12. Основные гипотезы до запуска

### H1

На реальном ConceptNet существует хотя бы один интервал из двух или более последовательных уровней, где Haken-based coarsening при `c=0.35` существенно уменьшает число узлов, сохраняя число и геометрию slow modes.

### H2

Режим `c=0.50` даёт большую cross-scale distortion, чем `c=0.35`.

### H0

Никакого устойчивого плато нет: выбранные slow modes и их подпространство изменяются примерно так же быстро, как уменьшается граф.

## 13. Что этот эксперимент не доказывает

Даже положительный результат M5 сам по себе не докажет, что:

- естественный язык буквально подчиняется уравнениям Хакена;
- найденные slow modes являются строгими параметрами порядка;
- ConceptNet полностью представляет семантическое пространство языка;
- Haken-coarsening лучше обычного spectral/community coarsening;
- найденная иерархия универсальна для других языков или корпусов.

Для этих утверждений нужны baselines, slaving tests, другие графы и повторения.

Эксперимент должен сохранять:

- SHA-256 скачанного ConceptNet dump;
- SHA-256 извлечённого 100k TSV;
- отчёт двухпроходного отбора;
- подготовленную sparse adjacency;
- список выбранных ConceptNet URI;
- все уровни hierarchy;
- membership каждого coarse node в исходных URI;
- plateau report;
- stdout основных стадий;
- версии Python и библиотек;
- commit SHA исходного кода.

**SHA-256** — криптографический отпечаток файла. Если файл изменится хотя бы на один байт, его SHA-256 почти наверняка изменится; поэтому он позволяет точно удостовериться, какие данные использовались.
