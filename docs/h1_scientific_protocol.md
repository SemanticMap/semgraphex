# H1: проверка статистической многоуровневости — исполняемый протокол

**Статус:** реализован исследовательский конвейер; научная гипотеза пока **не проверена на ConceptNet-100k**. Реальный вызов graph-tool проходит отдельный интеграционный тест CI с версией Ubuntu 2.59. CUDA используется в существующем \`estimate_block_kernel\`, но **не** при минимизации MDL graph-tool.

## Восемь реализованных направлений

1. **Graph-tool и воспроизводимость:** три направленные типизированные модели \`SBM / DC-SBM / nested-DC-SBM\`, явный режим независимых слоёв, поддержка старой и новой API, реальный интеграционный тест.
2. **Отложенная проверка:** \`splits.py\` делит группы одинаковых и обратных утверждений, сохраняя словарь узлов; ни одно тестовое отношение не участвует в оценивании степеней.
3. **Повторные оптимизации:** \`runner.py\` запускает K независимых инициализаций для всех трёх моделей, на каждой сети выбирает минимальный найденный MDL и показывает разброс.
4. **Прогноз:** \`predict.py\` сравнивает ранги скрытых направленных типизированных связей (MRR, Hits@10) при общих кандидатах. Используется **сглаженная блочная интенсивность**, а НЕ полная апостериорная вероятность graph-tool; логарифмическое правдоподобие теста не заявлено.
5. **Два нулевых ансамбля:** (а) независимое сопоставление направленных концов по типу отношения при точном сохранении степеней; (б) микроканонический условный одноуровневый DC-SBM по блокам, найденным только в обучении. Оба допускают петли и кратные рёбра. Никаких недоказанных заявлений о перемешивании MCMC в ансамбле (а).
6. **Статистика:** контрольный выигрыш по MDL, эмпирическое значение p с поправкой +1, Holm для двух проверок, оценка эффекта, кластерный бутстрэп разницы MRR, консервативный статус supported/not_supported/inconclusive.
7. **Ресурсы и RESUME:** \`runner.py\` сохраняет каждый fit и разбиения отдельно, пишет итог только после завершения, проверяет хэш графа, конфигурацию и версии исходного кода; \`spawn\`, общий бюджет CPU/OpenMP и RAM, меммап-массивы и одна кэшированная сеть на процесс. Промежуточные нулевые графы не размножаются на диске.
8. **Проверка на искусственных сетях:** \`synthetic_benchmarks.py\` и \`scripts/calibrate_h1_synthetic.py\` измеряют долю ложных подтверждений на плоских сетях и мощность на заведомо вложенных. **Этот полный статистический эксперимент требует отдельного реального вычислительного запуска; наличие генератора ещё не означает подтверждённой калибровки.**

## Научная постановка

Основная проверяемая разность (в битах):

\`\`\`
T(G) = best_MDL_DC-SBM(G_train) - best_MDL_nested-DC-SBM(G_train)
\`\`\`

\`T>0\` ещё не подтверждает H1. Сравнивается распределение T на обоих ансамблях по одинаковым K инициализациям. Нетривиальные уровни подсчитываются без корня и тождественного разбиения; нужна воспроизводимость на независимых выборках для H2. Требуется также отсутствие неприемлемого ухудшения прогноза nested относительно DC-SBM, проверяемого кластерным бутстрэпом на отложенных связях. При нескольких нулевых сравнениях значения p корректируются методом Холма.

Измеряемые параметры **условны по графу и протоколу наблюдения**. Отрицательные кандидаты для ранжирования — ненаблюдаемые связи, а не подтверждённые ложные утверждения. Апостериорная неопределённость nSBM, posterior predictive likelihood и доказательство семантической причинности здесь отсутствуют.

## Установка

Основной пакет:

\`\`\`bash
python -m pip install -e '.[dev]'
\`\`\`

**Для H1 обязательно \`graph-tool\`.** Он не входит в стандартные pip-зависимости. Ubuntu 24.04:

\`\`\`bash
sudo apt-get update && sudo apt-get install -y python3-graph-tool python3-scipy python3-yaml
PYTHONPATH=src:. /usr/bin/python3 -m semmap_haken.hypothesis.h1_cli --help
\`\`\`

Для Colab желательно отдельное совместимое conda-окружение; не пытайтесь копировать бинарные библиотеки \`graph-tool\` из другого Python. Notebook должен оставаться тонкой оболочкой вокруг командной строки.

## Запуск на подготовленной выборке

Нужен заранее сформированный направленный типизированный TSV утверждений ConceptNet, **а не произвольный префикс исходного дампа**.

\`\`\`bash
semmap-h1 \\
  --input data/conceptnet_en_10k.tsv \\
  --output tmp/runs/h1-cn10k-01 \\
  --mode NEW --seed 42 --restarts 10 \\
  --nulls 99 --workers auto --negatives 100
\`\`\`

После потери сессии повторить ту же команду с \`--mode RESUME\` и теми же параметрами и версией кода. Для пилота можно уменьшить \`--nulls\`, но тогда эмпирическая p-значимость может оказаться слишком грубой для заключения H1. \`--nulls 99\` означает 99 реализаций **каждого из двух** ансамблей; каждый повторно обучается со всеми K инициализациями для каждой модели.

Результаты хранятся на быстром локальном диске: \`manifest.json\`, \`data/\`, \`tasks/*.json\` и \`*.npz\`, \`nulls/*.json\`, \`report.json\`, \`COMPLETED\`. Для Colab сохраняйте в Google Drive только завершённые промежуточные метаданные / архив или результаты по этапам, копируя их из \`/content\`. Самая дорогая фаза может занимать много времени: \`3×K×(1+2N)\` оптимизаций.

## Калибровка ложных подтверждений

\`\`\`bash
PYTHONPATH=src:. python scripts/calibrate_h1_synthetic.py \\
  --output tmp/runs/h1-calibration-01 \\
  --simulations 20 --restarts 3 --nulls 99 --workers auto
\`\`\`

Отчёт \`calibration.json\` содержит вероятность ложного подтверждения на плоском контроле (оценка типа-I ошибки), вероятность обнаружения на вложенном, интервалы и сведения о каждом запуске. **Нужно увидеть отчёт, прежде чем утверждать, что проверка статистически откалибрована**.

## Ограничения и незавершённое

- Конкретный предел графонов/графексов и W/S/I здесь не оценивается; это другой этап диссертации.
- H1 сравнивает связи и их типы/направления, а не эмпирические веса ConceptNet.
- Модельный нулевой ансамбль условен по единственной оптимальной плоской классификации. Это не полный байесовский бутстрэп неопределённости блоков.
- Реплицируемость на RuWordNet и независимой сети из корпуса относится к H2/H4, не к этому выпуску.
- Нет доказательства математического обменного предела; полноразмерный ConceptNet-100k и L4-паритет отдельно не проверены.
